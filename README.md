# Logistic Regression Classification

## Overview

Binary classification project using **Logistic Regression** on the Breast Cancer Wisconsin dataset.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Work Done

* Data preprocessing
* Train-test split
* Feature scaling using StandardScaler
* Logistic Regression model
* Confusion Matrix
* Accuracy, Precision & Recall
* ROC-AUC and ROC Curve
* Sigmoid Function
* Threshold Tuning

## Dataset

* `0` → Benign
* `1` → Malignant

## Conclusion

Implemented and evaluated a Logistic Regression model for binary classification and studied threshold tuning and the Sigmoid Function.
